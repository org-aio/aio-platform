# 配对设备的局域网传输

宿主通过 `AIO_LAN_ORIGINS`（最多四个逗号分隔的 HTTPS 来源）公布受信任的局域网入口。入口必须使用浏览器和系统信任的证书、解析到私网并代理到同一个宿主进程；不要把数据库、设备凭据、CDP 或其他管理服务暴露到入口。

`GET /api/runtime/transport` 返回 `data.public_origin` 和 `data.lan_origins`，仅用于无凭据发现与探测。设备将候选按既有配对来源缓存；验证私网地址、TLS 和宿主归属后，通用 worker 请求、Codex WebSocket 与 restic 归档统一优先使用局域网。原配对来源、设备身份和加密用途不变。

浏览器 SDK 的设备视图使用宿主注入的同一清单。探测不带 Cookie；视图仍使用原来按用户、租户、插件版本和挂载限定的短期票据，撤销在每次读取和通道消息时验证。普通账号 API 继续使用登录页面来源。HTTPS 页面到局域网可能需要浏览器的本地网络访问许可；不可达或权限被拒绝时回退公网。

用户入口及分享链接使用公共来源，不要求用户访问局域网域名。局域网来源仅供内部探测、设备资源和通道选路。声明设备视图能力的插件由宿主在外层和内层 iframe 逐层委派 `local-network-access` / `local-network`，否则公共网页内的不透明沙箱会在探测前被浏览器权限策略拒绝。此委派不授予浏览器权限，不添加 `allow-same-origin`；用户拒绝本地网络访问时仍走公网。其他插件不获得此委派，设备视图的 CSP 继续限定在当前挂载的路径。

首页在壳模块启动前注入静态资源选路。同源 `/assets/*-dxh<hash>.*` 的普通 fetch GET（包括壳 WASM）优先无 Cookie 读取受信任的局域网副本；每个候选最多等待 2 秒，完整接收成功后交付。不可达、错误文档、断流均回退原公共请求，失败候选冷却 30 秒。账户 API、写操作、外域 URL、带查询串或显式凭据/请求头的请求不参与此逻辑；静态 CORS 只开放指纹资产，HTML 不开放。预加载不再同时下载公网 WASM。地址栏、登录来源和分享链接保持公共域名，首页快照失败不影响此选路。

局域网连接失败后设备为该入口冷却 30 秒；后续请求重新选择。失败的业务请求不会自动重放，已建立的通道不会为了周期探测而主动重开。设备断线后仍需遵守原有任务租约和结果确认规则。

原版 Renderer 初始化时可能连续发送大量消息。宿主为每个网页保留独立缓冲，最多 256 帧且不超过 32 MiB，按序交付；共享设备 reader 不等待某个网页消费。网页尚未加载、关闭或缓冲满时都不会阻塞其他视图的消息和资源回包；超过独立缓冲上限只关闭该视图，用户重新连接后从原生状态恢复。设备身份、跨挂载隔离和撤权校验仍在原有边界执行。

局域网响应使用管理员声明且匹配请求 Host 的来源构造资源和 WebSocket 地址。不接受任意 Host 或 `X-Forwarded-Host`，CSP 仅增加该视图票据下的资产路径及只读探测路径。
