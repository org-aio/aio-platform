# 插件运行时

这里保存公网壳的租户插件目录、Git 安装事务、页面定义协议和浏览器运行时渲染。正式状态写入 PostgreSQL，Git checkout 只作为版本化构建缓存。

`actions` 页面由壳渲染按钮，但状态归插件租户实例所有。浏览器只提交页面和动作 ID；服务端从 PostgreSQL 活动组合解析所属来源，重新校验页面权限与已发布动作，再注入用户和租户上下文。插件结果只能替换当前 `PageBody`，不能在事件中改写页面身份、导航、场景或权限。

## 前端缓存与租户生命周期

- 运行时 iframe 使用共享 `.application-frontend` 样式填满壳的可用内容区，随视口和侧栏变化调整尺寸，不再限制为固定 640px；插件内部滚动保持由插件负责。

- 登录会话摘要标识一棵壳组件树；租户 ID、权限摘要与插件活动版本标识页面实例。工作区全局最多保留 6 页，账户全屏页最多 2 页，超限淘汰最久未访问实例。
- 同租户导航仅隐藏页面。切换租户保留已加载的运行时 iframe 和 UI 状态，但停止续租、中止请求并撤销服务票据；返回后按当前权限和活动版本重新签发票据，不重新创建 iframe。仍依赖宿主全局上下文的原生业务页面不跨租户保留。
- 跨租户保留不是复用授权：旧票据永不恢复，非当前租户页面不能调用服务。版本、权限或登录会话变化会销毁不再有效的实例。快速切换期间尚未完成挂载的页面拒绝上下文错配，允许重新打开。
- 隔离 iframe 使用不透明源，其浏览器缓存无法可靠跨刷新复用。宿主 CacheStorage 按会话、文件摘要与文件扩展名保存经校验的不可变资源，限 96 MiB/512 项；当前挂载版本的资源清单控制可读取的摘要，相同内容和类型的文件可跨插件、跨文件名复用。ES 模块通过固定版本模块加载器使用宿主缓存，Wasm/字体等包内 fetch 同样复用。HTML、桥脚本、普通经典脚本与样式标签仍经过鉴权资源端点，不缓存业务响应或票据。
- 完整刷新仍需新建浏览器 UI 运行时，但不再重复下载已缓存的大型模块与 Wasm；纯内存状态不会跨刷新保留，需由插件自行持久化。切换登录会话或退出清理资源缓存；浏览器拒绝缓存时降级为校验后下载。
- 包内资源遇到传输失败、429 或服务端暂时不可用时最多尝试三次，每次限制 120 秒。授权拒绝、摘要不匹配与页面主动取消不重试；业务请求仍使用原有短超时，避免大资源下载改变服务调用语义。
- v1 与 v2 页面共用宿主摘要缓存。登录后的可访问前端页面在后台按队列预热模块、Wasm、字体及至少 256 KiB 的大资源；同版本与同摘要资源合并，最多 2 个资源并发、80 MiB/480 项，保留前台缓存余量。节流网络或省流量模式跳过预热，标签页隐藏时暂停后续资源。
- 字节预热使用临时挂载票据，逐页完成或取消后立即撤销。会话、租户权限或活动版本变更会停止旧任务。预热和前台共享下载，后台取消时前台以自己的票据接管。
- 完成资源预热后，按最近使用顺序提前准备最多 2 个桌面或 1 个移动端页面，计入现有 6 页容量且不淘汰已访问页面。准备中的 iframe 隐藏且不可交互，可提前实例化 Wasm；浏览器暂停隐藏帧绘制时，首次可见才完成首帧。单页准备超时停止后续实例准备，但继续字节预热。点击直接显示同一实例，刷新后复用字节并重新准备实例。
- 统一生命周期桥将首次激活前的业务请求延后，激活后才开始请求超时；待激活队列最多 16 项，跨租户暂停时拒绝等待请求。未访问的准备实例不跨租户保留，不能提前执行业务写入或模型调用。资源与生命周期通信不受业务门控影响。
- 服务端 Wasmtime 编译结果保存到宿主本地缓存，重启和重复验证复用同配置的机器码；缓存由运行引擎管理，限 512 MiB/4096 项，升级引擎或配置自动区分。包验证同时生成不可变前端摘要与大小，挂载不再遍历资源重新哈希。
- 插件可通过 `aioPlugin.visible` / `onVisibilityChange` 暂停后台动画、轮询；壳不把局部状态操作转换成后端请求。沙箱不开放 `allow-same-origin`、Cookie、宿主 DOM 或任意网络权限。

验证：`node --test tests/browser/asset_cache.cjs tests/browser/asset_preload.cjs`；`node tests/browser/preparation.cjs` 检查真实 Compose 后台零业务调用、预备实例首次交互、刷新和画布计数；`node tests/browser/keepalive.cjs` 覆盖桌面/移动端、A/B/A 状态隔离、旧票据撤销、刷新资源复用、会话失效和 LRU。真实服务端测试使用 `AIO_TEST_DATABASE_URL` 的隔离数据库。
