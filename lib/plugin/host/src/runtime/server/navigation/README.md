# 租户插件菜单

菜单隐藏按租户与插件来源保存，覆盖当前及后续版本的全部插件入口。管理插件中的“隐藏菜单 / 显示菜单”只修改导航偏好，不停用或卸载插件，不修改授权、激活代次、业务数据库或对象存储。其他租户的显示状态独立。

完整运行目录保留所有已授权页面；`hidden_pages` 由工作台用于过滤菜单及预热。隐藏菜单不等于访问控制。

## 导航标签覆盖

除隐藏菜单外，租户还可以覆盖三类显示名：场景页签（`scene`）、菜单分组（`menu`）和插件
页面或账户入口（`page`）。覆盖只改写 `label`，页面标识、挂载入口、权限、菜单层级和
激活代次保持原样，因此不改授权、不迁移业务数据，也不影响预热与访问控制。其他租户的
覆盖互相独立。

键取自当前租户目录：场景键是场景 id（如 `system`），菜单键是分组 id（如
`component-<source>-0-系统管理`），页面键是页面 id（如 `component:<source>:users`）。
只有已存在于目录中的元素才能被覆盖，未知键返回 404。管理插件通过
`POST /api/runtime/navigation/labels` 设置或更新，`DELETE` 恢复整包声明的默认显示名；
两者都要求 `plugin:manage`。当前生效的覆盖随目录返回在 `navigation_labels`。
