# 工作区启动

首屏与目录轮询共享一个经过实时鉴权的快照，权限与目录来自同一次会话读取。客户端只在当前页面内保存快照及 ETag；服务端每次仍验证会话和权限，未变化时返回 304。

首页 HTML 携带刚验证的快照，Wasm 启动后直接读取并移除 JSON 节点，首屏无需追加 API 请求。HTML 使用 `private, no-store`，不接受条件缓存；JSON 转义左尖括号，不能结束脚本节点。无法生成快照时交付壳，由客户端执行有界请求与重试。

每次请求包含响应体读取在内最多等待 8 秒，网络失败或 5xx 最多重试一次。刷新期间保留已显示的工作区，未完成的请求不会被定时轮询取消；首次失败提供重试操作。快照不写入本地存储。
